# Demo script (about two minutes)

“This is the CPU prototype of BhashaGuard Edge. The examples are synthetic, so they demonstrate checking behaviour without claiming to represent a real tradition.”

1. Start `python -m bhashaguard serve` and open the local address.
2. Select **Telugu: supported fixture**, analyse it and open the cited excerpt.
3. Select **Telugu: contradicted fixture**. Explain that the contradiction is explicitly curated within this invented example.
4. Select **Telugu: unresolved fixture**. Point out that a missing source leads to abstention.
5. Load a supported fixture and append ` AI`. Rerun, then enable Latin exclusion and compare the script numerator/denominator.
6. Change locale to `another:locale`. Show the context mismatch without assigning a false factual verdict.
7. Export the report. Show evidence IDs, the pack hash and actual CPU timing.

“The next research step is a reviewed cultural pack and held-out native-speaker evaluation. The next device step is validating a matching model/runtime on a Snapdragon-powered HP PC. Neither benchmark accuracy nor NPU acceleration is claimed in this demo.”

If optional model weights are unavailable, use pasted text. Do not describe the fixture selector as LLM generation.
